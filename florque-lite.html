Core Innovation

Why Mobile Planning Needs an Agent

Traditional todo apps let ideas rot in infinite lists. Florque Lite introduces an agent that actively evaluates constraints, schedules realistically, and heals broken plans.

mic

1. Raw Idea Ingestion

Speak voice memos or drop unstructured bullet points while on the run. The agent parses the core intent, filters out noise, and extracts tangible project milestones.

"Voice Note: Need to launch payment portal by next Friday..." → Synthesizing milestones & deps.
hourglass_bottom

2. Resource-Constrained Engine

Most plans fail because they ignore capacity. Florque Lite models real available hours and energy levels, generating plans that fit within actual boundaries.

Available budget: 14 hrs/week. Optimization calculates critical path fit: 100%.
autorenew

3. Dynamic Roadmap Healing

When unexpected blockers appear or you miss a day, Florque Lite doesn't pile on red badges. It dynamically recalculates paths and reorganizes priorities seamlessly.

Blocker detected on API keys → Downstream tasks rescheduled safely.
Under The Hood

Lightweight Agent Architecture

Florque Lite leverages edge reasoning and local state caches to provide instant response times on mobile devices, syncing back with the comprehensive Florque Work Graph engine whenever online.

Natural Language Parsing Kernel

Token-efficient extraction of tasks, dependencies, durations, and urgency from unstructured sentences.

Adaptive Constraint Solver

Balances task dependencies against real-world user calendar availability using heuristic graph scheduling.

Full Florque Graph Compatibility

Export or promote lightweight roadmaps into full VSGT work graphs in Florque whenever a project scales up.
